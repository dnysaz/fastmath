# FastMath

Quick mental math practice with timed questions, multiple choice or type-in answers, and instant results.

## What it does

- Practice addition, subtraction, multiplication, and division
- Choose 1-digit, 2-digit, or 3-digit number ranges
- Multiple Choice or Type Answer mode
- Timed practice with correct / wrong tracking
- Fastest answer time recorded
- Auto-advance option (type mode)
- Stop-on-wrong rule toggle
- Shareable result summary (copy to clipboard / native share)

## How to use

Open `index.html` in any modern browser, or deploy to Vercel / Netlify / GitHub Pages.

No build step required — pure HTML, CSS, and vanilla JavaScript.

## Tech stack

- HTML5 + CSS3 (no external framework)
- Vanilla JavaScript (ES6+)
- Google Fonts: Outfit

## Files

- `index.html` — UI and layout
- `styles.css` — styling
- `app.js` — game logic, questions, scoring, sharing
- `og-math.svg` — Open Graph preview image
